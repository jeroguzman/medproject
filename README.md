# medproject · VozClínica

Asistente de documentación clínica por voz (hackathon). Todos los datos son ficticios.

- [`docs/REQUERIMIENTOS.md`](docs/REQUERIMIENTOS.md): requerimientos del MVP.
- [`docs/equipo/`](docs/equipo/): guía de cada integrante.
- [`frontend/`](frontend/): aplicación del médico en React (guía de German), que sirve de referencia. Ver [`frontend/README.md`](frontend/README.md).
- [`docs/equipo/lovable/`](docs/equipo/lovable/README.md): paquete para construir el frontend en Lovable (prompts, capturas de referencia, conocimiento del proyecto) y el backlog de Linear en CSV.
